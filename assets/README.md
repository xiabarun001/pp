# 换肤说明

仓库不带形象图片(见 README 素材声明),放你自己的图即可:把图片帧放进各状态子目录即可:

```
assets/
  idle/        待机(必须有,其他状态缺帧时都退回用它)
  success/     测试通过
  fail/        测试有 Fail
  attention/   需要人介入
  urgent/      着急(最紧急的事)
  cry/         大哭(测试大面积崩)
  angry/       生气
  hello/       打招呼(启动和问候时挥手用)
  config.json  可选,{"fps": 8} 控制帧率
```

规则:

- 每个目录里放一张或多张 PNG/GIF/WebP,多张时按文件名排序轮播(建议 `01.png`、`02.png`…);
- 只放一张也行,会静止显示,但仍然有整体的浮动/弹跳动画;
- 建议正方形、透明背景,200×200 以上;
- 放好后在桌宠上右键选「重新加载形象」,或重启桌宠;
- 全部清空则使用内置的 SVG 小检查员形象。
